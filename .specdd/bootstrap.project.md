# SpecDD project specific overrides

- All code must be minimally commented following best software development practices.
- The repository root is the SpecDD content root for this example.
- `example.sdd` is the root application spec.
- `src/src.sdd` governs only the `src/` source tree.
- Tests live in `tests/` folder, same level as `src/`. Tests do not mix with source.
